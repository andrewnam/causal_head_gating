# Causal Head Gating

Accompanying repository for the paper *Causal Head Gating: A Framework for Interpreting Roles of Attention Heads in Transformers* by Andrew Nam, Henry Conklin, Yukang Yang, Thomas Griffiths, Jonathan Cohen, and Sarah-Jane Leslie, published in NeurIPS 2025.

This repository only contains files for the experiments reported in the paper. For a more user-friendly package, see the companion repository at <https://github.com/jonhanke/nam_causal-head-gating>.

**Latest version:** <https://arxiv.org/abs/2505.13737>
